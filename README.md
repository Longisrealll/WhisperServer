# WhisperServer
## Setting up

Use requirement.txt to download neccesary libraries

## Run the project

*'This works on window, though it is not yet tested on Linux or Mac'*
Use the code `cd testing` to go into the testing folder

Run `unifcorn STT_api_calls:app --reload`, then access the link to html web page
It needs 30s-1min for them to boot up
